# Prezintazii

Редактор презентаций в браузере. Откройте `index.html` — ничего устанавливать не нужно.

- слайды (добавить, копировать, удалить), миниатюры
- текст, заголовки, картинки (файл или ссылка), фигуры
- перетаскивание и изменение размера, форматирование, цвет фона
- показ на весь экран (стрелки, Esc), экспорт в PDF через печать
- автосохранение в браузере, сохранение/открытие файлом .json
